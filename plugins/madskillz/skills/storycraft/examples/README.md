# Sample output — "The Sock Goblin"

A complete, **auto-generated** demonstration produced by the `storycraft` pipeline itself
(co-design → per-chapter draft + editorial panel + Editor-in-Chief → story-bible updates →
repetition scan → EPUB/PDF render). It shows the full artifact set the skill creates:

- `book.yaml` — the per-book config
- `bible/` — the canon (premise, characters, world, outline, timeline, style-guide, glossary)
- `chapters/` — the drafted + edited chapters
- `build/` — the rendered `.epub` (e-reader) and `.pdf` (Typst)

A 2-chapter early-chapter-book for ages 7–9, generated as a pipeline smoke test (not hand-edited).
During its making the continuity check caught a real bible contradiction (sock-loss rule), which
was corrected at the checkpoint — a small live demonstration of the consistency backbone.
