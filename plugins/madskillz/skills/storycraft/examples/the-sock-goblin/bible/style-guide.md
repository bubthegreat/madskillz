# Style guide
- POV third-limited on Pib (ch.1 leans Mar-observed, but stay close to Pib once caught); past tense.
- Short sentences; concrete sensory detail; gentle humor. Ages 7-9 vocabulary.
- Dialogue does real work — no filler beats. **Banned (verbatim, scanner-enforced):** "nodded", "just nodded", "nodded slowly", "shrugged". Vary reactions with action+voice instead.
- Pib's verbal tic: "technically." Use sparingly (not every line).
