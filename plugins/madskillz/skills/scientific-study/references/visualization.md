# Visualization conventions

All data figures generated by study scripts (`scripts/generate-figures.py`) must use
**seaborn** as the primary visualization library. Matplotlib is available as the
underlying engine and for elements seaborn cannot produce (flowcharts, decision trees,
patch-based annotations, arrows, custom legends).

## Required setup

Every `scripts/generate-figures.py` must include seaborn in the PEP 723 inline
dependency header:

```python
# /// script
# dependencies = ["matplotlib>=3.7", "numpy>=1.24", "seaborn>=0.13"]
# ///
```

And apply the default theme at module level, before any figure function is called:

```python
import seaborn as sns
sns.set_theme(style="whitegrid", palette="muted", font_scale=1.05)
```

## When to use seaborn's high-level API

- **Bar charts / count data**: `sns.barplot()` or retain `ax.bar()` with seaborn
  theme applied — theme alone is sufficient for most cases.
- **Scatter / point plots**: `sns.scatterplot()` preferred.
- **Heatmaps / matrices**: `sns.heatmap()`.
- **Distribution plots**: `sns.histplot()` / `sns.kdeplot()`.
- **Line / time-series**: `sns.lineplot()` preferred over `ax.plot()`.

## When to fall back to matplotlib

- Flowcharts and decision trees (patch boxes, FancyArrowPatch)
- Annotated diagrams with custom arrow routing
- Any figure requiring non-data graphical elements as the primary content

In these cases: apply `sns.set_theme()` globally so that font, color, and grid
styling is still seaborn-consistent, then use matplotlib patches/artists directly.

## Palette conventions

Use the seaborn `"muted"` palette by default. Override per-figure only when the
domain meaning of color requires it (e.g., red for danger, green for safe). Never
use the bare matplotlib default color cycle.

## Figure size and DPI

- Standard data figure: `figsize=(8, 4.5)` — 16:9, readable in PDF and EPUB.
- Two-panel figure: `figsize=(10, 4.5)`.
- Square or matrix figure: `figsize=(7, 6)`.
- Save at 150 DPI: `fig.savefig(path, dpi=150, bbox_inches="tight")`.
