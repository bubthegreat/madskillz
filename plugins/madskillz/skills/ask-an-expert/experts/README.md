# Experts library

Reusable domain-expert personas, one per file: `<concise-name>.md` (kebab-case = the
expertise). Shared by the whole `scientific-*` research family and by direct
`ask-an-expert` queries.

- **Format:** see `../references/expert-format.md`.
- **Adding one:** the finder (`../references/find-the-right-expert.md`) derives the real
  requirements, reuses or extends an existing expert when possible, and only then mints a new
  file. A minted/updated expert is challenged once by the adversarial reviewer before use.
- **Reuse first.** Before creating a file here, check whether an existing expert already covers
  the need — extend it rather than spawning a near-duplicate.

## Current personas

Seeded from the ACI organizational-power study (their first home). Several are tuned to that
study — `organizational-power-theory`, `philosophy-of-social-science`, `normative-ethics`,
`systems-theory`, and especially `curious-peer-reviewer` (written in that study's originator's
voice) and `think-tank-liaison` — so when reusing them elsewhere, **read the Scope/Boundaries and
re-tune the Provenance** rather than assuming a clean general fit. `research-data-sourcing` and
`software-architecture-simulation` are the most domain-general.

- `organizational-power-theory.md` — power/org theory, the general case (systems of people).
- `philosophy-of-social-science.md` — construct validity, ontology, fact/value firewall.
- `normative-ethics.md` — meta-ethics & applied ethics.
- `systems-theory.md` — systems/dynamics; inputs→entity→outputs under bounded observability.
- `research-data-sourcing.md` — dataset discovery, vetting, acquisition-strategy.
- `software-architecture-simulation.md` — Python framework-modeling & agent-based simulation design.
- `curious-peer-reviewer.md` — integrative gap-finder (originator-voice; holistic review).
- `think-tank-liaison.md` — expert-generalist & research integrator (roster adequacy + cycle-control).
